SCR triggering explained

Positive U–V–W sequence: vU = Vm sin(θ), with V and W lagging by 120° and 240°. The first natural diode commutation is 30°; the first gate window starts at 30° + α, then repeats every 60°.

A logical 1 means adequate G–K drive. The SCR starts only when forward eligible and then stays latched until its current reaches zero or ideal commutation transfers it. Gate removal cannot turn it off.

Both members of each incoming pair are driven together, including retriggering the member shared with the preceding pair. This explicitly supports discontinuous current.

Circuit and current path

T₁/T₂/T₃ connect U/V/W to +. T₄/T₅/T₆ return current from − to U/V/W. The source block supplies the balanced phase voltages; its neutral N is not connected to the load. Wire crossings without a dot are separate conductors. Every gate driver returns locally to its SCR’s K.

Each sine-wave circle is an AC phase source. The sources share the internal star point N; vU, vV, vW are phase-to-neutral voltages. Only U, V and W connect to the bridge: there is no neutral wire.

Model and equations

During source conduction: L dio/dt + Rio + E = vo = upath − ndVF. Set L or E to zero when that series element is absent. During blocked intervals, io = 0 and vo = E.

For R‖C with RC > 0: iR = vo/R, iC = (vo − vC)/RC = C dvC/dt. When blocked, io = 0, iC = −iR, and vC decays with time constant (R + RC)C. Capacitor voltage stays continuous; output voltage can jump at firing.

Ideal SCRs use adequate gate drive, zero latching/holding thresholds and zero recovery time. No finite source inductance or overlap is modeled. This resolves teaching waveforms, not device ratings or a hardware gate-drive design.

Predict, test, explain

Predict what changing α from 0° to 60° does to the resistive-load mean voltage. Prepare the case, inspect the gate and current windows, then explain the result.

Reveal the explanation

Delayed firing removes part of the resistive conduction interval. The complete source-current waveform, rather than a cosine rule assumed for continuous inductive current, determines this result.

With an opposing DC load, compare a 5° gate window and a wide window at the same delay. Predict whether the source becomes eligible before the gate ends.

Reveal the explanation

A gate pulse can finish before the blocked load can accept current. A longer gate window can then initiate conduction when the source overtakes the load voltage. Once current is established, the gate ending does not interrupt it.

Prepare R‖C. Compare output-current RMS with resistor-current RMS and locate the largest charging pulse. Predict the effect of reducing RC; confirm that capacitor voltage remains continuous.

Reveal the explanation

The resistor sees iR = vo/R. The rectifier must also charge C, so its RMS current can be much larger. RC limits the charging pulse and dissipates RC iC²; it also slightly changes the voltage seen by R. A very small RC is not zero.

Source-current spectrum and power factor

For the sinusoidal source, PF = P/S = DPF × DF. DPF = cos(φ₁); DF = fundamental-current RMS / complete source-current RMS. Ratios are undefined if their denominator is zero. A negative PF indicates net regeneration.

Conventions, limitations and data

U, V and W name phase terminals; italic R names resistance. Current subscript R means the load resistor. The main R‖C current cards refer to that branch. All means, RMS values and spectra use one complete source period, not just the conduction interval.

Periodic steady state with ideal sinusoidal voltage sources. No startup, source impedance, finite commutation overlap, recovery, leakage, temperature or transformer model is included. The small charging resistor is the only extra element in the capacitor branch; it is not source resistance. Current peaks are model results, not safe device ratings.

When every bridge device is blocked, individual AC-to-DC device voltages require a common-mode or leakage model that is absent here. The displayed state describes complete current paths and actual device currents; it does not invent those floating terminal voltages.

Piecewise periodic solutions use bracketed switching events, stable linear-ODE convolution and quadrature split at those events and time constants. The laboratory checks current signs, Kirchhoff and branch laws, state continuity, and instantaneous and periodic power balances before accepting results. No arbitrary minimum L or C is used.

CSV uses SI units and a decimal point. Its event-enhanced grid is not uniform. At a jump, equal angles with limit_side = left/right give exact one-sided states. Source/phase current, complete output current, resistor current and capacitor-branch current have distinct columns. THD fields are dimensionless ratios; displayed THD is a percentage.
