DESCRIPTION
Interactive HTML Learning Resources for Power Electronics is a collection of thirteen interactive HTML laboratories by Alejandro Gómez Yepes, Universidade de Vigo, for university-level learning of power electronics, instructor demonstrations, guided activities and independent study.

Version 1.0.1 contains laboratories on power semiconductor devices; control and protection in power electronics; mean and RMS value calculation; Fourier harmonic decomposition; three-phase electrical system review; four uncontrolled rectifiers; and four controlled rectifiers. Each rectifier group includes single-phase half-wave, single-phase full-wave, three-phase half-wave and three-phase full-wave circuits.

The interfaces are available in English, Spanish and Galician. The HTML files contain their own interface, styling and scripts. Start from index.html to choose a laboratory; individual laboratories can also be opened directly in a modern browser with JavaScript enabled. Keep the delivered HTML filenames together to preserve the index links and links between laboratories.

Prerequisites are basic circuit analysis, resistor/inductor/capacitor behavior, elementary algebra and trigonometry, and sinusoidal AC signals. The three review laboratories support revision of mean/RMS values, Fourier harmonics and three-phase systems. Learners are encouraged to read the explanations and model assumptions, predict outcomes, vary parameters, compare plots and calculated values, and explain their observations. Activities, questions and export tools vary by laboratory. Twelve laboratories retain notes and assessment records only in local browser storage when it is available; the RMS/mean laboratory (03) keeps them only in the open page. Export a copy before reloading, closing, moving or replacing files. Numerical CSVs and self-assessment TXT records are separate in Fourier and the rectifier laboratories; offline and hosted browser work does not automatically transfer or synchronise.

Dedicated laboratories on inverters and DC/DC converters are planned for future versions. Version 1.0.1 contains the thirteen laboratories described above. Some controlled-rectifier laboratories already address inverting operation under suitable circuit conditions. The package includes a browser-readable documentation page, user guide, collection description and model limits, citation instructions, change log, exact file manifest, SHA-256 checksums and licence notices.
