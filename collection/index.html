Using this collection

Intended audience

University students learning power electronics, instructors using demonstrations or guided activities, and independent learners with basic circuit knowledge.

Prerequisites

Basic circuit analysis, the behavior of resistors, inductors and capacitors, elementary algebra and trigonometry, and sinusoidal AC signals. The review laboratories help you revisit mean/RMS values, Fourier harmonics and three-phase systems.

Languages

English, Spanish and Galician. Select a language on this page and inside each laboratory; each laboratory remembers its own preference when browser storage is available. The collection title stays in English in every interface.

How to start

  1. Choose a laboratory below and select your preferred language.
  2. Read the explanations and model assumptions. Predict the result, change a parameter, and compare the calculated values and plots.
  3. Use the activities and questions where provided. Explain what you observe, and export notes or answers with the available tools before closing or replacing a file.

Current release

Power semiconductor devices; control and protection; three reviews on mean/RMS values, Fourier harmonics and three-phase systems; and eight rectifier laboratories: four uncontrolled and four controlled, covering single-phase and three-phase half-wave and full-wave circuits.

Planned additions

Dedicated laboratories on inverters and DC/DC converters are planned for future versions. The current collection provides the thirteen laboratories listed below.
