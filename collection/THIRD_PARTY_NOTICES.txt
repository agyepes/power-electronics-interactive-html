GRAPHICAL REFERENCE NOTES

The control-and-protection implementation records graphical references
checked for circuit-symbol conventions: ST TN1215/TYN612 (SCR),
ST AN316 Figure 1 (TVS polarity), TI SLUA618A Figure 10 (complementary
driver), and KiCad Device.lib (fuse/MOV conventions). This is a source
acknowledgement, not a grant of rights in those reference works or libraries.
No KiCad library file is included in the collection.

The Fourier laboratory cites MathWorks THD documentation for a convention
and states that it calculates its ratios directly, without using that
reference algorithm. MathWorks software is not included.
