User guide

Start from index.html. The 13 laboratories run in a browser and can be used online or from an extracted download. Keep an exported copy of your work: browser saving is convenient, but it is not a portable backup.

Open the collection

For online use, open the collection website. For offline use, obtain the complete version 1.0 ZIP from the GitHub release and follow these steps:

  1. Extract the whole downloaded collection into a normal folder before opening it. Keep the delivered filenames and all files together. Opening an HTML inside a ZIP preview can prevent the collection links from working.
  2. Open index.html in a browser with JavaScript enabled. Use Go to the laboratories and choose a resource. You can also open a numbered HTML directly.
  3. Select EN, ES or GL inside the laboratory. The interfaces provide English, Spanish and Galician. On a first opening without a saved preference, they start in English; each laboratory can remember its own last language when storage is available.
  4. Read the model assumptions, predict an outcome, change one parameter, and explain the resulting plots and values. Choose a learning level where the laboratory offers one; higher levels reveal additional material.
  5. Answer the self-assessment before revealing its solution. Questions use the conditions stated in their wording, independently of the current slider settings.
  6. Export your work before leaving, reloading, clearing browser data or changing files. Open the downloaded export and check that your notes are present.

Use the browser's Open link in new tab action to compare laboratories. Ordinary collection links use the same tab; leaving the RMS/mean laboratory can therefore discard its unexported work.

For laboratory 05, the saved state also includes such settings as source amplitude, frequency, cursor and voltage probes. For the other laboratories, record the operating point with the numerical export or a PDF rather than relying on settings surviving a reload.

Browser work depends on the browser profile and the storage context. Moving or renaming downloaded files, changing browser or computer, clearing site data, or using private browsing can make earlier work unavailable. Local-file storage behaviour also varies between browsers. Do not expect notes or answers to transfer between an offline file and the hosted website, or between different website addresses. Export them before changing context. The existing TXT and CSV exports provide readable records; this collection does not provide a general file-import or automatic synchronisation facility.

Choose the appropriate export

TXT records preserve student notes and the self-assessment information supplied by that laboratory. CSV files preserve numerical data and the settings or provenance included by the model. In Fourier and the rectifier laboratories, a numerical CSV does not contain the self-assessment notes: export both files when you need both kinds of work.

For laboratory 06, choose the Advanced level to reach the waveform and metric CSV controls. In laboratory 02, each model has its own CSV control. Laboratory 01 and laboratory 03 provide their work in TXT rather than a separate numerical CSV.

Exports include a laboratory identifier and the internal HTML release identifier, distinct from collection version 1.0. Keep the generated filename to help identify the export. A date in an exported filename is the export date, not the collection publication date.

Import CSV files into a spreadsheet using comma-separated fields and a decimal point. Read the header and metadata rows for units and definitions. Some exports include extra rows at switching events, one-sided limits or distinct repeating intervals; do not assume that every time step is uniform. Undefined physical ratios can have blank entries as described by the laboratory; they should not be converted automatically to zero.

If a calculation fails, follow the on-page error message and correct the settings or use its retry control. Numerical export and application printing can be disabled until a valid result is available. Student-work exports remain available where the interface provides them; laboratory 03 has the separate Export notes and answers only control.

Print or save a PDF

Use the laboratory's Print / PDF control, then choose a printer or the browser's PDF destination. Check the preview for the chosen language, operating point, notes, questions and the available solution options. Print controls and options differ between laboratories; the self-assessment may offer Include solutions when printing and Include explanations of incorrect options.

Keep a TXT export when the answer history matters. A printed worksheet is not a replacement for every item in the electronic self-assessment record. A PDF preserves a snapshot of the display; the HTML remains the interactive resource.

This documentation page can also be printed using the browser's Print command. Browser and printer settings can change page breaks and colours.

Use the collection offline

The laboratory HTMLs contain their scripts, styling, calculations and drawings. No installation, account, server or internet connection is needed for the teaching interactions after extracting the collection. JavaScript must be enabled. Optional links to external references require an internet connection.

Keep index.html, the numbered HTMLs and the accompanying documents together. Export your work to a folder you can find, and retain those exports separately before updating the collection. Keeping a filename stable helps navigation, but it does not guarantee continuity of browser-local work.

Recover or clear work carefully

If a laboratory reports earlier saved work that could not be interpreted or no longer matches its current questions, export that work before erasing it. The recovery material may be included in the TXT export; it may need to be read manually rather than appearing as current answers.

Read the confirmation before using Erase, Delete my notes and quiz record, or an equivalent control. Resetting a circuit or waveform and erasing student work are separate actions. Export first if you need to keep the record.

Self-assessment results are for learning and practice. They are not an official course grade. The collection has no automatic submission to an instructor or learning management system; follow your instructor's submission instructions when a task requires delivery.

Collection description

This collection supports university-level Power Electronics teaching through interactive explanations, calculations, plots, guided investigations and self-assessment. It is intended for students, instructors preparing demonstrations or guided activities, and independent learners with basic circuit knowledge.

Scope of version 1.0

The collection contains 13 laboratories and one laboratory homepage. Its topics are power semiconductor devices, control and protection, mean/RMS values, Fourier harmonics, balanced three-phase voltages, four diode rectifiers and four SCR rectifiers. The accompanying documentation page is a guide, not an additional laboratory.

The 194 authored self-assessment questions are distributed across these 13 laboratories. The question count exposed at a particular learning level can be smaller. Additional conceptual checks and investigations are provided where the laboratory offers them.

Dedicated laboratories on inverters and DC/DC converters are planned for future versions; they are not modules in this release. Some existing controlled-rectifier laboratories already discuss or calculate inverting operation under suitable circuit conditions.

Prerequisites

Learners should know Kirchhoff's laws, basic resistor/inductor/capacitor behaviour, elementary algebra and trigonometry, and sinusoidal AC signals. Mean/RMS and Fourier work benefits from basic integration and harmonic representation. The more advanced inductive and capacitive rectifier sections use circuit differential equations, switching intervals and steady periodic operation. The three review laboratories help revisit the corresponding foundations.

Common learning objectives

After appropriate study, learners should be able to identify voltage and current reference directions; distinguish peak, RMS, mean and instantaneous quantities; predict conduction paths before using a plot; relate parameters to waveforms, device currents, power and harmonics; and explain when an analytical formula applies.

The laboratories encourage a cycle of prediction, parameter change, observation and explanation. Students can use local notes and self-assessment to record that reasoning, then export a portable record. These activities support learning; local quiz results are not formal course grades.

Model assumptions and limitations

The on-page definitions and assumptions govern each model. Use the offered parameter ranges and the actual active load configuration. The following overview identifies the main limits needed when interpreting or comparing results.

On a narrow screen, scroll the table horizontally to read all columns.

Modules Important modelling limits
01 Device characteristics, loss waveforms, reverse recovery, gate charge, SCR/GTO actions and IGBT tail current are simplified or illustrative models. The steady thermal network has no thermal dynamics or temperature feedback into electrical loss. A favourable result does not establish device ratings or safe operating area.
02 The separate drive, isolation, triggering and protection models each have their own scope. RC gate models omit the Miller effect and do not predict drain/collector switching times; imposed flux and fault envelopes do not establish transformer saturation or real fuse operation. Thermal networks are steady-state; snubber, clamp, coordination and crowbar examples do not constitute hardware/component selection.
03 Prescribed ideal periodic current waveforms, not a load-circuit simulation. Mean/RMS calculations use analytical expressions; plot sampling is for drawing. Heating examples use a constant 2 Ω resistor. Meter bandwidth, transients, switching loss and temperature dependence are outside the model.
04 Metrics describe the active finite Fourier reconstruction. Changing the maximum order, order filter or enabled components changes the analyzed waveform. The optional ideal reference and its complete-waveform metrics are separate. The ideal rectifier source-current presets assume sinusoidal sources, ideal diodes and a pure resistive load.
05 Ideal balanced sinusoidal voltages with a fixed U–V–W sequence, equal phase peaks and an ideal neutral reference. It constructs voltage differences and envelopes; it does not calculate load/neutral currents, power or semiconductor states. The √3 and 30° relations require the stated balance, waveform and voltage ordering.
06–13 Periodic steady-state rectifier models with prescribed sinusoidal sources; the three-phase sources are balanced. Device drops use the constant-drop option where offered. Startup, source/transformer impedance, finite commutation overlap, reverse recovery, leakage, switching loss and temperature are excluded. Ideal charging-current peaks are not safe component ratings.
10–13 SCR rectifier models assume adequate logical gate drive, zero latching/holding thresholds and zero recovery time. They explain circuit conduction rather than validate a real SCR driver. The firing-angle cosine rule needs continuous series current and its other stated conditions. A firing angle above 90° alone does not establish inversion.

For capacitor-filter comparisons, match the circuit branch explicitly. The diode filters in 06–08 use the ideal capacitor branch. Laboratory 09 offers both an ideal branch and a branch with a small charging resistance; the controlled rectifiers use the specified resistance in the capacitor branch. That resistor is not an AC-source resistance. Match this choice, active load, voltage convention, device drops and periodic state before comparing diode and SCR circuits.

For three-phase rectifiers, the input amplitude is phase-to-neutral peak; for a single-phase bridge it is the complete source peak. The half-wave three-phase topology has a neutral return, while the full-wave bridge uses three line conductors. Laboratories 09 and 13 show all six directed line voltages by default in Source and output voltages; phase voltages have a separate toggle and are initially hidden. Display toggles do not change the physical calculation.

Distinguish the resistor current from the complete rectifier output current when a capacitor branch is active. Check the stated denominator for distortion, power factor and efficiency. An undefined ratio is not a zero result. If a laboratory offers established and zero-current-start periodic states, use its stated conditions; selecting a state does not simulate the complete startup transient.

These models support circuit reasoning within their disclosed assumptions. Real hardware also requires appropriate datasheets, parasitic and thermal behaviour, ratings, layout, insulation and experimental validation.

Identify an exact package

The public collection label is 1.0. Individual HTMLs also retain internal release identifiers and parent provenance, which identify their source revisions. MANIFEST.json records the current file sizes, SHA-256 values and HTML provenance; SHA256SUMS.txt includes the manifest's own hash.

The two integrity files cannot both include their own hashes without a circular dependency. MANIFEST.json therefore inventories every package file except MANIFEST.json and SHA256SUMS.txt. SHA256SUMS.txt hashes every package file except itself, including MANIFEST.json. The manifest also records the complete expected filename set.

Regenerate both integrity files after any content or metadata edit. A checksum establishes equality with the bytes listed in this package; it does not independently authenticate the author or a download source. Keep the final released archive and its externally recorded archive checksum with the publication record.
